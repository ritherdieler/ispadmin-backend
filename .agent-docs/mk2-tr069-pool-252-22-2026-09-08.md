# MK2 / VPS — pool TR-069 ampliado a `192.168.252.0/22`

**Fecha:** 2026-09-08  
**Motivo:** el pool DHCP staging `provisioning-255` (antes `.100–.250` en `/24`) se agotó (~151 IPs; ~174 leases bound).

## Estado aplicado

| Pieza | Valor |
|-------|--------|
| Gateway MK2 | `192.168.255.1/22` en `sfp-sfpplus2` (misma IP que leases viejas) |
| Red connected | `192.168.252.0/22` |
| DHCP network | `192.168.252.0/22`, gateway `192.168.255.1`, DNS `8.8.8.8,8.8.4.4` |
| Pool | `192.168.252.2–192.168.255.254` (~1021) |
| NAT | `masquerade src=192.168.252.0/22` |
| Firewall CR / forward | `dst/src 192.168.252.0/22` |
| address-list `staging-tr069-255` | `192.168.252.0/22` |
| VPS `wg-olt` AllowedIPs + rutas | `192.168.252.0/22` (reemplaza `192.168.255.0/24`) |

- Pool e2e `192.168.250.0/24` no cambia.
