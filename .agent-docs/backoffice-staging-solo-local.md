# Backoffice staging = solo local

El proyecto `ispadmin-backoffice` en modo staging **nunca** se despliega al VPS. Un «deploy staging» es el WAR (`/ispadmin-staging`), no el front.

Vite en la Mac `--mode staging` → `https://api.gigafiberperu.cloud/ispadmin-staging`.

`https://gigafiberperu.cloud/backoffice-staging/` es la **landing**.

Regla Cursor: `gigafiber/.cursor/rules/backoffice-staging-solo-local.mdc`.
