# gf-tr069-vlan1000 — fallo lab y corrección (2026-09-18)

Lab VSOL `B46415-V2804AX15T-12345B4641531C0B6` (`VSOL0031C0B6`, tag `lab`). WAN invertida: WCD.1 internet PPPoE VLAN 100, WCD.2 TR-069 DHCP `192.168.254.206` VLAN 100.

## Qué pasó

PUT + task NBI `provisions` a las 15:27:22Z: HTTP 200, task `6aad585a52ae2eddfa5cb996`. Inform `2 PERIODIC,6 CONNECTION REQUEST` a las 15:27:24Z. En `genieacs-cwmp-access.log` **no hubo** `Script: gf-tr069-vlan1000`. Solo corrió `gf-inform-interval`. VLAN TR-069 siguió en 100, IP `192.168.254.206`. Internet no se tocó. No se aplicó a ninguna ONU fuera de lab.

Causa: el mock de tests devolvía un **array** de matches para `declare(wildcard)`. En GenieACS 1.2 `declare()` es un `ParameterWrapper` (`.size` / `.path` / `.value` del primero; iterable con `for-of`, **sin** `.length`). `eachDeclared` no visitaba instancias, no hacía GPN y no llegaba a SPV. Los tests verdes no reproducían el sandbox.

## Corrección (TDD)

Mock por defecto = ParameterWrapper no array. Pruebas nuevas (VLAN hoja string; wrapper sin `.length`). Discovery: un wildcard por nivel (`WANConnectionDevice.*`, luego `WANIPConnection.*` / `WANPPPConnection.*`); si el wrapper no itera, sondeo `.path` de instancias 1..8. Identificación sigue siendo pool `192.168.252.0/22` + VLAN 100 (no un índice WCD fijo). Args NBI como string (`"1000"`).

```bash
node --test scripts/genieacs/provisions/test/gf-tr069-vlan1000.test.js
# 9 pass
./gradlew :core:test --tests "GenieAcsVirtualParametersTest.tr069_vlan1000_finds_mgmt_wan_by_dhcp_pool_and_never_hardcodes_wcd_index"
```

Aplicar solo lab:

```bash
GENIEACS_NBI_URL=http://127.0.0.1:7557 ./scripts/genieacs/retag-tr069-vlan1000.sh --lab
```

Éxito: `Script: gf-tr069-vlan1000 retag … vlan=1000`, IP TR-069 en `10.20.0.0/22`, CR vivo. Si lab falla, no tocar parque.
